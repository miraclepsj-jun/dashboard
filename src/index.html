  1. 불러오기 통합문서(.xlsm) 또는 일정관리 프로그램 복사분 붙여넣기
  2. 자동 일정수립 납기순으로 적은 호기에 길게, 방(조)별로 분산 가배정
  3. 검토·수정 간트/품목에서 호기 변경, 수기검토 품목 배정
  4. 내보내기 9번 확정시트 붙여넣기용 + 설비1~A 입력요약
