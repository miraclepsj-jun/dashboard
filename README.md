# CNC 가공일정 수립

800대 규모 CNC 가공현장의 일정을 **품목별 수기 입력 없이 한 번에 가배정**하는 도구입니다.
기존 엑셀 통합문서(`CNC 생산계획 자동화` v629 / 매크로 v666)의 시트와 판정 규칙을 그대로 읽어 쓰므로,
마스터 관리 방식은 바꾸지 않고 **"품목 하나씩 호기추천 → 확정 → 다음 품목" 반복만 없앱니다.**

- 설치 없음: `dist/CNC_일정수립.html` 파일 하나를 크롬/엣지에서 열면 됩니다 (인터넷 없이 동작, 글꼴만 기본 글꼴로 대체).
- 데이터는 PC 밖으로 나가지 않습니다. 파일은 브라우저 안에서만 읽고 계산합니다.
- 원본 통합문서는 수정하지 않습니다. 결과는 별도 엑셀 또는 복사/붙여넣기로 옮깁니다.

| 순서 | 할 일 | 화면 |

| 2 | **[자동 일정수립]** – 미배정·추가배정 전 품목을 납기순으로 가배정 (2,500여 품목 기준 약 3~4초) | 상단 |
| 3 | **간트차트** 에서 결과 확인, 막대를 눌러 호기 변경 / **수기검토** 탭에서 자동기준 밖 품목 처리 | 탭 |

다음 날 다시 불러오면 9번 확정분은 "확정"으로, 새 발주만 가배정 대상으로 잡힙니다.

## 자동 일정수립 규칙

기존 매크로의 판정을 그대로 사용합니다. 실제 통합문서(2,739행)로 검증한 결과
`7_배정대상`의 대분류·세부분류·생산성분류·기준일생산량·필요장비일수·권장장비대수·상태가 **전 행 일치**했습니다.

1. **품목 분류** – `5_생산성분류` 우선순위 순 첫 일치 규칙(포함/앞2자리/끝일치/본체끝문자), 대분류는 부품코드 앞 2자리
2. **필요 장비일수** – `올림(발주량 ÷ 기준_일생산량) + 여유일(Y=1일)`, 권장대수 1 / 2 / 2~3 / 3~5 / 수동검토(40일 초과)
3. **후보 호기** – `3_방마스터`(허용대분류·기본소재계열·우선생산성분류·특수방), `4_설비마스터`(일정표기대상·신규셋팅가능·PL/TE/BD가공가능·BD 외경/길이), U품목은 P033 전용, `21_BD규격마스터`
4. **등급** – A(방 점수 150 이상 또는 소재계열 일치+현재소재 일치) / B-2차후보 / C-조건부(도면확인, 자동선택 안 함), 작업상태로 A-즉시·A-예약·A-일정주의 구분
5. **가용일** – `9_설비배정_확정` 구간을 피해 필요한 일수가 연속으로 들어가는 첫 빈 구간. 누적실적 ≥ 계획수량이면 최근실적일 다음날 해제, 완료일이 지났는데 미완료면 **완료확인 필요**(신규배정 제외)
6. **배분** – 여러 대면 가장 먼저 끝나는 호기에 하루씩 배분, 수량은 100개 단위 비례배분(잔여는 가장 긴 호기)

일괄배정에서 추가된 부분:

- **처리 순서**: 특별관리 Y → 요청일 빠른 순 → 장비일수 큰 순. 앞 품목의 가배정이 뒤 품목의 가용일에 바로 반영됩니다.
- **배정 방식 – 분산형(기본, 현장방식)**: 수량이 많아도 가능한 호기를 한꺼번에 쓰지 않고, **가공기간을 요청일까지 늘려 적은 호기**로 편성합니다.
  - 목표 가공기간 = 요청일까지 남은 일수를 `최소 가공기간(7일)` ~ `최대 가공기간(30일)` 범위로 맞춘 값, 호기 수 = 올림(장비일수 ÷ 목표기간), 최대 6대
  - 요청일이 최소 가공기간 이상 남았는데 늦어질 때만 한 대씩 늘립니다. 이미 요청일이 지난 품목에 호기를 몰아넣지 않습니다.
  - **조(방) 분산**: 조는 **방** 기준입니다(4_설비마스터 `방` 열, 없으면 13_작업자운영마스터 `방` 열). 한 품목은 한 방에 1대까지만 넣고 다른 방의 가능한 호기로 나눕니다. 그 품목이 갈 수 있는 방이 모자랄 때만(예: TK 품목은 5·6번방) 같은 방에 고르게 더 넣습니다.
  - **반 하루 신규셋팅 한도 = 반 인원 × 1인 한도(기본 5건)**: 호기별 담당작업자 지정 대신 반(방)별 인원으로 운영합니다. 한 반에서 같은 날 시작하는 신규 셋팅이 `반 인원 × 5건`을 넘으면 다음 날로 미룹니다. 반별 인원은 [기준 설정] → 반별 인원(`1번방 = 6`, 한 줄에 하나)에서, 비어 있으면 3_방마스터 `인원` 열에서 읽고, 둘 다 없는 반은 한도를 적용하지 않습니다. 9번 확정일정의 시작도 함께 세고, 같은 부품을 바로 이어 가공하는 경우는 신규셋팅으로 세지 않습니다.
- **배정 방식 – 집중형**: 이전 방식(권장대수 1/2/2~3/3~5로 최단 완료). [기준 설정]에서 고를 수 있습니다.
- **방마스터 우선**: 후보 호기를 방마스터 적합 단계로 나눠 앞 단계부터 씁니다.
  1. 기본소재계열과 우선생산성분류가 모두 맞는 방(방마스터 1순위)
  2. 소재계열만 맞고 현재소재도 같은 A등급 호기 – 1단계 호기가 모자랄 때만
  3. B-2차후보 – 그래도 기본 대수가 모자랄 때만 보충
  같은 단계 안에서는 먼저 비는 호기(동일부품 연속가공 1일 우대) 순서로, 방(조)마다 1대씩 씁니다 (같은 조건이면 그날 셋팅이 적은 반의 호기 우선).
  C-조건부·일정주의·완료확인 필요 호기는 자동선택하지 않습니다. 실제 통합문서 기준 1순위 방 배정이 1,089행 → 1,375행(전체 1,727행)으로 늘었습니다.
- **납기초과는 담당자가 조정**: 요청일을 넘겨도 자동으로 호기를 더 늘리지 않습니다(설정에서 켤 수 있음). 납기초과 품목은 수기검토 탭 "납기 초과 – 담당자 조정 필요"에 모이고, 품목 상세에서
  - 가배정표의 **호기·시작일·장비일·수량을 바꿔 [적용]** – 다른 일정과 겹치면 거절하고 이유를 보여줍니다. **[겹치는 뒤 가배정은 뒤로 밀기]**를 켜면(기본) 연장한 만큼 뒤쪽 가배정을 밀어냅니다(확정·고장 일정은 움직이지 않음).
  - **[호기 추가·재배분]** – 현재 호기를 그대로 두고 다른 호기를 더해 수량을 다시 나눕니다.
  - **[지연 확인 완료]** – 이대로 진행하기로 한 품목을 "지연확인" 상태로 분리합니다. 일정을 다시 바꾸면 확인이 풀립니다.
  - 담당자가 조정한 품목은 [자동 일정수립]을 다시 실행해도 그대로 유지됩니다.
- **작업자운영**: `13_작업자운영마스터` 상태구분에 "고장"과 시작·종료일이 있으면 그 기간은 배정하지 않습니다. 그 밖의 상태(연차/교육)와 신규세팅금지는 기존처럼 점수 감점과 비고로만 표시합니다.

실제 통합문서(9/28 기준, 작업자 53명) 비교: 집중형은 한 품목 최대 10대·같은 방에 2대 이상 248품목·1인 하루 신규셋팅 최대 14건,
분산형은 한 품목 최대 6대·같은 방에 2대 이상 43품목(갈 수 있는 방이 적은 품목)·1인 하루 신규셋팅 최대 5건 (가배정 1,522건, 납기초과 14건은 동일 – 모두 요청일이 이미 지난 품목).

### 기존 매크로와 다르게 처리한 것

- **5번방 소재계열**: 방마스터 5번방 기본소재계열이 `TK/H3J` 인데 매크로는 문자열 완전일치로 비교해 TK 품목과 연결되지 않았습니다(5번방 97대가 추천에서 빠짐). 이 도구는 `/` 로 나눈 항목 중 하나만 맞으면 일치로 봅니다.
- **완료 판정**: 사용안내(0번 시트) 기준대로 "누적실적 ≥ 계획수량 + 최근실적일"이면 완료로 봅니다. 실적확인=Y까지 요구하려면 [기준 설정]에서 바꿀 수 있습니다.
- 품목별 CT/실적 기반 가점(v544/v553)은 아직 반영하지 않았습니다. 확정이력 가점과 연속가공 우선은 반영했습니다.

## 화면

- **품목 목록**: 상태(미배정/가배정/가배정(지연)/수기검토/배정완료…), 가배정 호기와 기간, 판정 사유. 행을 누르면 상세.
- **간트차트**: 방별 호기 행. 막대에 **부품코드**를 표시하고 **같은 부품은 같은 색**(일정이 가까운 부품끼리는 서로 다른 색). 확정=실선, 가배정=빗금+점선 테두리, 요청일 초과=빨간 테두리, 고장=회색 빗금, 완료확인 필요=빨간 점선. 막대에 마우스를 올리면 같은 부품의 다른 호기 막대가 함께 강조되고, 누르면 품목 상세.
- **품목 상세**: 후보 호기표(등급·조·현재소재·작업상태·가용구간·점수·비고, 20_가능호기조회와 같은 항목, 분산형 기준으로 미리 선택), 체크하거나 `527/528` 형식으로 입력 → [배분 미리보기] → [선택호기 가배정].
- **기준 점검**: 반(방)별 호기 수·인원·하루 셋팅 한도와 기존 확정/가배정의 하루 최대 셋팅, 방별 부하와 최종완료일, 소재계열 미매핑 재질, 생산성기준 미등록 분류, 완료확인 필요 호기, BD규격 미등록 부품.

가배정은 같은 브라우저에 자동 저장되어 같은 파일 이름을 다시 불러오면 복원됩니다.

## 현장 학습 (수기 간트) – v671 반영판

**현장 학습** 탭에서 담당자가 직접 그린 방별 수기 간트(.xlsx)를 불러오면 실제 배정 습관을 수치로 뽑아 자동배정과 나란히 보여줍니다.
수기 간트 형식: 시트=방, 1행=날짜(일), A열=호기, 시작 칸에 `부품코드/수량K(같이 도는 호기)` + 가공기간만큼 색칠.

가공1팀 수기 간트(2026-09-28~11-18, 작업 334건)에서 배운 내용:

| 수량대 | 수기 호기 수(중앙/최대) | 수기 가공기간 | 기준 대비 장비일 | 자동(학습보정 후) |
|---|---|---|---|---|
| 1만 개 미만 | 1 / 1 | 1일 | ×0.5 (여유일 없이 하루) | 1 / 1, 1일 |
| 1만~5만 | 1 / 3 | 9일 | ×1.4 | 1 / 3, 8일 |
| 5만~15만 | 2 / 4 | 25일 | ×1.45 | 2 / 5, 21일 |
| 15만 이상 | 5 / 13 | 27일 | ×1.15 | 6 / 6, 34일 |

- 여러 호기 작업의 86%는 **한 방 안**에서, 대부분 **담당작업자가 서로 다른 호기**로 편성하고, 같은 날 동시에 시작합니다 (자동배정: 한 방 안 89%).
- 실제 계획 일생산량은 기준의 약 절반입니다 (AR 2,233 / 기준 5,000, 커터 1,500 / 3,000, BD 2,810 / 4,000). 셋팅·대기일을 포함한 계획 기준입니다.
- 수기 배정의 23%는 방마스터 밖입니다 (예: BECU AR 품목을 1번방, H5J 품목을 6번방). H5J는 TK 계열 방에 23/27 구간 → `H5J=TK` 매핑 제안.

## 사내망(내부망) 사용 방법 – 엑셀 반출 없이

이 프로그램은 **인터넷 웹사이트가 아니라 HTML 파일 하나**입니다. 크롬·엣지 브라우저를 계산 화면으로만 쓰고, 엑셀 자료를 어디에도 올리지 않습니다.

- **외부 통신 없음**: 파일 안에 보안정책(Content-Security-Policy)을 넣어 브라우저가 외부 서버로 요청하는 것 자체를 막습니다. 웹폰트도 빼고 PC 기본 글꼴(맑은 고딕)만 씁니다. 엑셀 읽기 라이브러리(SheetJS)도 파일 안에 들어 있습니다.
- **저장 위치**: 불러오거나 붙여넣은 기준은 그 PC 브라우저 저장소(IndexedDB/localStorage)에만 남습니다. [시트 붙여넣기] → [이 PC 저장 지우기]로 지울 수 있습니다.
- **필요한 것**: 엣지(크로미움) 또는 크롬. 인터넷 익스플로러는 지원하지 않습니다.

### 반입 방법 (셋 중 하나)
1. **로컬 실행 (권장)**: `CNC_일정수립.html` 한 개를 내부망 PC로 반입(외부→내부)해 바탕화면 등에 두고 더블클릭. 엑셀은 반출할 필요가 없습니다. 보안 프로그램이 .html 반입을 막으면 zip으로 묶어 반입 신청합니다.
2. **NAS 공유 폴더**: `\\NAS\공유\CNC_일정수립.html`에 두고 각 PC에서 더블클릭(또는 바로가기). 새 버전은 NAS 파일만 바꾸면 모두 같은 버전을 씁니다. 저장된 기준·가배정은 PC(브라우저)마다 따로 남습니다.
3. **NAS 웹서버(시놀로지 Web Station 등)**: 내부망 주소(예: `http://nas/cnc/`)로 같은 HTML을 올려 두면 주소 하나로 씁니다. 서버는 파일만 전달하고 계산·데이터는 각 PC 브라우저 안에서만 처리됩니다.

### 엑셀 파일을 직접 못 여는 경우 (문서보안/DRM)
사내 문서보안 프로그램이 엑셀 파일을 암호화하면 브라우저가 .xlsm을 읽지 못합니다. 이때는 **시트 붙여넣기**를 씁니다.
1. 처음 한 번: 엑셀에서 3·4·5·6·9·13·16·21·23·28번 시트를 각각 열고 Ctrl+A → Ctrl+C → 프로그램 [시트 붙여넣기]에 Ctrl+V → [이 시트 반영]. 어느 시트인지는 머리행으로 자동 판정합니다.
2. 매일: 1_원본(일정관리 프로그램 복사분)과 바뀐 9번만 붙여넣기 → [자동 일정수립] → 검토 → [결과 엑셀 내보내기] 또는 9번 붙여넣기 행 복사.
3. 날짜 열은 연도가 보이는 서식(yyyy-mm-dd)이면 가장 정확합니다. `10/19`처럼 연도가 없으면 오늘에서 가장 가까운 해로 읽고, 9번 완료일이 시작일보다 앞서면 다음 해로 봅니다.
4. 1_원본 설비1~A 열에 날짜 서식이 걸린 칸(예: 131 → `05월 10일`)은 호기로 쓰지 않고 [기준 점검]에 알립니다. 해당 열 서식을 "일반"으로 바꾸고 복사하세요.
